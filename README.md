# 8总办公室突袭模拟器 · 游戏版

一个纯前端、单文件的 vibe coding 练手小游戏。

## 玩法

你在办公室里摸鱼，门开着。虚构监督官「8总」会随机推门进来贴脸质问「你在干锤子？」。你要在限时内按 **Alt+Tab**（或空格 / 回车 / 点按钮）把绿色的摸鱼画面切成蓝色工作画面。

核心博弈：摸鱼越久，「摸鱼赌注」倍率越高、得分越高，但 8总下次来得越快、切窗时间越短——贪心 vs 保命。切慢了 / 没切到就当场暴击（红章盖戳），累计 3 次进「绩效小黑屋」。

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖或构建。

## 技术

- 纯 HTML / CSS / JS 单文件，无框架
- WebAudio 合成音效，CSS 动画驱动状态机
- localStorage 存最高分

## 说明

「8总」为虚构角色，与任何真实人物无关，纯属娱乐练手。
